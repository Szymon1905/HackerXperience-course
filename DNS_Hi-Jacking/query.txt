================================================================================
                       DNS QUERY PACKET STRUCTURE (CLIENT)                      
================================================================================

+------------------------------------------------------------------------------+
| 1. DNS HEADER (12 Bytes)                                                     |
+------------------------------------------------------------------------------+
| Field                         | Length  | Example / Value                    |
+-------------------------------+---------+------------------------------------+
| Transaction ID (id)           | 16 bits | Random uint16 (e.g., 0x1234)       |
| Flags (QR|Opcode|AA|TC|RD...) | 16 bits | 0x0100 (Standard Query, RD=1)      |
| QDCOUNT (Question Count)      | 16 bits | 0x0001 (1 question)                |
| ANCOUNT (Answer Count)        | 16 bits | 0x0000 (0 answers)                 |
| NSCOUNT (Authority Count)     | 16 bits | 0x0000 (0 records)                 |
| ARCOUNT (Additional Count)    | 16 bits | 0x0000 (0 records)                 |
+------------------------------------------------------------------------------+

+------------------------------------------------------------------------------+
| 2. QUESTION SECTION                                                          |
+------------------------------------------------------------------------------+
| Field                         | Format / Length                              |
+-------------------------------+----------------------------------------------+
| QNAME (Domain Name)           | Length-Prefixed Labels:                      |
|                               | [3] "w" "w" "w"                              |
|                               | [6] "g" "o" "o" "g" "l" "e"                  |
|                               | [3] "c" "o" "m"                              |
|                               | [0] (Null Terminator byte)                   |
| QTYPE                         | 16 bits (e.g., 0x0001 for TYPE_A)           |
| QCLASS                        | 16 bits (e.g., 0x0001 for CLASS_IN)         |
+------------------------------------------------------------------------------+


================================================================================
                      DNS RESPONSE PACKET STRUCTURE (SERVER)                    
================================================================================

+------------------------------------------------------------------------------+
| 1. DNS HEADER (12 Bytes)                                                     |
+------------------------------------------------------------------------------+
| Field                         | Length  | Example / Value                    |
+-------------------------------+---------+------------------------------------+
| Transaction ID (id)           | 16 bits | Matches Request ID (0x1234)        |
| Flags (QR|Opcode|AA|TC|RD...) | 16 bits | 0x8180 (Response, No Errors, RD=1) |
| QDCOUNT (Question Count)      | 16 bits | 0x0001                             |
| ANCOUNT (Answer Count)        | 16 bits | 0x0001 (1 answer record included)  |
| NSCOUNT (Authority Count)     | 16 bits | 0x0000                             |
| ARCOUNT (Additional Count)    | 16 bits | 0x0000                             |
+------------------------------------------------------------------------------+

+------------------------------------------------------------------------------+
| 2. QUESTION SECTION (Echoed from query)                                      |
+------------------------------------------------------------------------------+
| QNAME                         | Encoded target domain name                   |
| QTYPE                         | 16 bits (0x0001 = TYPE_A)                    |
| QCLASS                        | 16 bits (0x0001 = CLASS_IN)                  |
+------------------------------------------------------------------------------+

+------------------------------------------------------------------------------+
| 3. ANSWER SECTION                                                            |
+------------------------------------------------------------------------------+
| Field                         | Length  | Example / Value                    |
+-------------------------------+---------+------------------------------------+
| NAME                          | Variable| Pointer to QNAME (0xC00C) or Label |
| TYPE                          | 16 bits | 0x0001 (TYPE_A)                    |
| CLASS                         | 16 bits | 0x0001 (CLASS_IN)                  |
| TTL                           | 32 bits | Time-To-Live in seconds (e.g., 300)|
| RDLENGTH                      | 16 bits | Length of RDATA (0x0004 for IPv4)  |
| RDATA                         | 4 bytes | Raw IP address (e.g., 142.250.1.100|
|                               |         | binary byte array)                 |
+------------------------------------------------------------------------------+
