# Repsoitory for Cybersecurity - The Hacking Xperience (2025-2026) course at Ecole Polytechnique in France.

A collection of cybersecurity challenges, experiments, and exercises.


## Overview

Challenges :

* Buffer Overflow exploit
* SYN flooding
* DHCP spoofing


## Tools Used

Some of the tools and technologies used throughout the challenges:

* Linux
* Wireshark
* Ghidra
* Burp Suite
* Nmap
* Python
* C/C++
* Bash scripting
* Virtual machines
